
Troubleshooting
___________________________________
Help with common situations you may run into


What if my question isn't answered here?
If your question isn't answered here, please read the Escape Velocity FAQ.text file that is included in the Escape Velocity package, and is also available on our web site.  This FAQ has numerous answers to questions we are frequently asked about Escape Velocity.

What is the "EV Plug-Ins" folder for?
The EV Plug-Ins folder allows mission designers to extend Escape Velocity by adding new worlds, weapons, missions, ships, etc.  While this is not for the faint of heart, several developers are working on editors that will allow people to do just that.  Please don't ask us about editors, etc. -- we aren't working on them, independent developers are.  We’re just providing the support mechanism for it in EV.

For the vast majority of people, the EV Plug-Ins folder is there to allow you to easily use scenerios that others have devised, simply by dropping them in the folder.

How can I pause a game of EV? Can I get to the Finder?
EV doesn't have a "Pause Key" as many of our other games have. The reason for this is because EV pauses when you open a dialog box (for example, the Map window). The game is also paused when you are on a planet.

If you would like to get to the Finder, you can use the ESC key to exit your ship (this is also a pausing technique). You can then hide EV from the Application menu or even quit the program while at the title screen. Keep in mind that EV only saves when you are on a planet, so it is a good idea not to use the ESC key until right after you leave a planet. 

Does EV work on my PowerPC - Is it PowerPC native?
EV works just fine on all PowerMacs. It is a "Fat" binary, which means it has native code for both the 68K and PPC machines.  EV senses the type of machine you are using and loads the proper code.

Why does the sound occasionally break up?
Certain video cards may cause the sound to break up during fades.  This is because all video card drivers turn off interrupts while they are changing color table entries, and some video cards do not handle color table changes in an optimal manner.  Since interrupts are off while the video card is changing color table entries, the Sound Manager cannot service the sound chip quickly enough, and the sound breaks up.

Will VM or RAM Doubler affect game play?
If you have Virtual Memory turned on or are using the RAM Doubler extension, it may slow down EV's game play.  This is unavoidable; the only solution is to turn virtual memory or RAM Doubler off before playing EV.

On slower machines, Virtual Memory or RAM Doubler may also cause the sound to breakup or screech on occasion.  We recommend against using Virtual Memory or RAM Doubler while playing EV (or any other game for that matter), but it does work.

I have problems launching EV - what can I do?
There are two things you can try. First, raise EV's memory allocation. This is done by hilighting the EV application icon from the Finder and choosing Get Info... from the File menu. You can set the memory allocation to a higher amount. EV requires at least 5800K of free RAM.

If you continue to have problems, try disabling the extensions on your machine before playing. This is done by restarting your machine while holding the Shift key down. You will see a message that says "Welcome to Macintosh - Extensions off." Sometimes extensions can conflict with other programs.

If your problems continue, please contact our technical support department.

I have a slower Macintosh (030 based machine) - is there anything I can do to improve game play?
EV can run on the 030 based Macintoshes, but the speed when flying from planet to planet can be slow. A good thing to do is to enable the double speed feature of EV. This is done by locking down the Caps Lock key. You will see a little "2x" in the upper right hand corner. This feature can also come in handy when the sector you are in is saturated with many ships and game play slows down. By using the double speed feature, battle maneuvers are much easier.

Can I use a joystick to play EV?
Yes. Escape Velocity will always need the use of the keyboard because of the amount of controls, however you can set up your joystick to fly your ship and shoot your weapons. Make sure that the settings for your joystick match those controls in the EV preferences dialog.

My License Code is invalid - What's wrong?
The license code you were sent is based on your name as you gave it to us when you registered. Make sure that you are entering your name exactly as it appears on your registration confirmation. If you still have a problem with your license code not working, please get in contact with us and we will take care of the situation for you.
