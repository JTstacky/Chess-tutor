EVSys, EVTimes and EVGeneva: stand-ins for the Mac system font (Charcoal/Chicago 12), Times 18 and Geneva 7
in EV Online's 1:1 client.

They are Modified Versions of the Liberation fonts 2.1.5 (Liberation Sans Bold, Liberation Serif Regular,
Liberation Sans Regular; Copyright (c) 2012 Red Hat, Inc., digitized data copyright (c) 2010 Google
Corporation), licensed under the SIL Open Font License 1.1 (OFL.txt). As the licence requires, they do
not use the Reserved Font Names "Liberation", "Arimo", "Tinos" or "Cousine".

Changes, made by tools/fonts/make-standins.py: subset to Latin; hinting, kerning and other OpenType layout
removed; outlines and metrics scaled so the cap height and line widths match the original game's screen.
