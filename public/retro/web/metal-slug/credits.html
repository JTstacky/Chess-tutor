Building the engine

Concatenate the four RetroArch parts in numerical order before extracting the gzip tar archive. Extract FinalBurn Neo into /build/fbneo and RetroArch into /build/retroarch-neogeo. Use Emscripten SDK 3.1.74. The integration archive includes tools/build-metal-slug-neogeo.sh with the exact compilation flags and tools/prepare-metal-slug-neogeo.py with the runtime instrumentation and packaging step (Python with py7zr). The build contains no original game data.
