Rebuilding

Concatenate each source archive's parts in numerical order, then extract under /build. Extract the build and integration archives under /workspace. Copy the extracted retroarch-flycast-eh-sync source tree to /build/retroarch as well. With Emscripten 3.1.74, run FLYCAST_SYNC=1 FLYCAST_WASM_EH=1 FLYCAST_NO_STUBS=1 FLYCAST_OPTIMIZE=1 bash /workspace/tools/build-metal-slug6.sh. Run the included prepare-flycast-runtime.py to package the output. No original game files are needed to compile the engine.
