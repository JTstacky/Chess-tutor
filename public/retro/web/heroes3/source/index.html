Heroes III source

The Heroes III page runs the open-source VCMI engine, built for the browser. The combined build is licensed under the GNU GPL version 3.

Download the complete corresponding source (66.6 MB, .tar.xz, build e53754d). It holds the patched VCMI and SDL2 sources, this page's code and build scripts, and library sources. Also download the Boost companion below; the README explains how to build. It contains no Heroes III game files.

Download Boost 1.86.0 source (90.8 MB). This companion contains the remaining build dependency.
