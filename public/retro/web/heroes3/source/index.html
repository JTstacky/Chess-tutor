Heroes III source

The Heroes III page runs the open-source VCMI engine, built for the browser. The combined build is licensed under the GNU GPL version 3.

Download the complete corresponding source (17.7 MB, .tar.xz, build 7554e7e). It holds the patched VCMI source, this page's code and build scripts, and the bundled libraries; its README lists the rest. It contains no Heroes III game files.
