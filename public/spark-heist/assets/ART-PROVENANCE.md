# Spark Heist original vector art

Created 13 November 2026 specifically for the owner's Prompt Wars reboot, by the Codex art task.

All artwork in this directory is newly authored SVG geometry. No downloaded pictures, stock packs, franchise references, copied game sprites, image traces, fonts, logos or outside source artwork were used. The brief was a warm miniature botanical workshop, with functional features that make each invention recognisable. Files contain no scripts, external URLs, remote images or embedded raster data.

The twelve icons and Spark use a transparent 128-by-128 viewBox. The hero uses a 900-by-520 viewBox. Faces, functional attachments, small highlights and a coordinated earthy outline are hand-authored path/shape choices. The hero reuses the same original visual designs through newly authored inline geometry. Internal `symbol`/`use` references in the hero never load an external resource.

`art-contact-sheet.png` is a QA preview rasterised from these SVGs in headless Chrome, not a separate source image. All fourteen SVGs decoded successfully, their XML parsed, and their source passed checks against scripts, foreign objects, text nodes, external image/resource references and raster embedding. The contact sheet was visually inspected at 1,200 pixels wide; all twelve creations have distinct silhouettes and the hero is unobstructed. No preview server was started and the temporary headless browser was closed.

Use descriptive filenames as identifiers. These images contain no printed names. The working game/mode names remain subject to normal product name review; this provenance record is about the independently created artwork and does not make a trademark-clearance claim.
